REQUIRED CHANGES FOR ONBOARDING.TSX:

1. Add import at top:
   import { usePlanLimits } from '../hooks/usePlanLimits';
   import { Link } from 'react-router-dom';

2. Inside the Onboarding component function, add:
   const { limits, plan } = usePlanLimits();

3. In the handleCompleteOnboarding function, before creating the brand, add validation:
   const activeQueries = queries.filter((q) => q.enabled);
   const maxAllowed = limits?.maxQueries || 15;

   if (activeQueries.length > maxAllowed) {
       setStep3Error(`Your ${plan} plan allows maximum ${maxAllowed} queries. You have ${activeQueries.length} selected. Please uncheck some queries or upgrade your plan.`);
       return;
   }

4. Add a visual indicator showing query count after the query list (in step 3):
   <div style={{ fontSize: '12px', color: 'var(--text-dim)', marginTop: '12px', padding: '8px', background: 'var(--panel-bg)', borderRadius: '6px' }}>
     {queries.filter(q => q.enabled).length} / {limits?.maxQueries || 15} queries selected
     {queries.filter(q => q.enabled).length >= (limits?.maxQueries || 15) && (
       <span style={{ color: 'var(--amber)', marginLeft: '8px', display: 'block', marginTop: '4px' }}>
         ⚠️ Limit reached. <Link to="/pricing" style={{ color: 'var(--amber)', textDecoration: 'underline' }}>Upgrade plan</Link> to add more.
       </span>
     )}
   </div>

These changes will:
- Fetch the user's current plan limits
- Validate query count before brand creation
- Show real-time feedback on query usage
- Provide upgrade link when limit is reached
