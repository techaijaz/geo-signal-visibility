# Fix Guide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every task the app gives a founder (recommendations, audit fix tips, generated fixes) shows who usually does it, plain steps for their store, and can be sent to their developer by email or copied for WhatsApp.

**Architecture:** A fixed library (`fixGuide.ts`) holds one guide per task kind. Every task source gets a `kind`; API responses carry the guides, `isShopify` and the brand's `developerEmail`. A new endpoint builds the developer email on the server from saved data and the library. One React component (`FixGuide`) renders the tag, steps and buttons everywhere.

**Tech Stack:** Node/Express + TypeScript + Mongoose (backend), React + TypeScript + Vite (frontend), checks are `ts-node` scripts in `backend/src/checks/` run with `NODE_ENV=development npx ts-node --transpile-only <file>`.

**Spec:** `docs/superpowers/specs/2026-10-17-fix-guide-design.md`

## Global Constraints

- All UI, step, email and error text in simple English. No Hinglish words (ke, ki, hai, liye, kaise, kya, aur, nahi…) anywhere in the library or new UI.
- Steps come only from the library; never AI-written.
- *Send to developer* and *Copy text* on every task; the who tag is a hint, never a gate.
- Developer email: saved per brand (`brand.developerEmail`), validated (format + `isDisposableEmail`), '' clears it.
- Email: Reply-To = founder, CC = founder, subject `<Brand>: <guide.title>`, built only from server data.
- Limit: 20 developer emails per brand per IST day; a failed send is refunded.
- `developerSends` log TTL 90 days.
- Commit subjects lower-case after the type (commitlint `subject-case`), header ≤ 100 chars, no Claude trailers.
- Run `npx tsc --noEmit -p .` in `backend/` and `npx tsc -b --noEmit` in `frontend/` before each commit (checks use `--transpile-only` and miss type errors). Run `npx prettier --write` on changed backend files.
- Local checks that load `config` must blank SMTP: prefix with `SMTP_HOST= SMTP_USER= SMTP_PASS=`.

## Review Focus

1. A founder whose brand has no saved developer email presses Send → the inline email box appears; no request with an empty email reaches the server (pinned in Task 5 UI step and Task 4 test "422 without email").
2. A recommendation text with code-like content (`<script>`, quotes) → appears escaped in the email HTML, never as markup (pinned in Task 4 test "escapes task text").
3. A store whose homepage could not be fetched (no audit HTML) and no Shopify products → `isShopify` false, generic steps shown, no crash (pinned in Task 3 test "no audit → not Shopify").
4. Old recommendations saved before `kind` existed → get a kind from text, never `undefined` in the response (pinned in Task 2 test on built-in texts + Task 3 response test).
5. Founder sends the same task twice quickly → two sends count against the limit, both succeed, `lastSentAt` shows the latest (pinned in Task 4 test "two sends").

    assert.ok(g.title.length >= 5 && g.title.length <= 60, `${kind} title`)
    for (const list of [g.steps.shopify, g.steps.other]) {

    const all = [g.title, g.forDeveloper, ...g.steps.shopify, ...g.steps.other].join(' ')

export const guideFor = (kind?: string | null): IFixGuide => FIX_GUIDES[(kind || '') as FixKind] ?? FIX_GUIDES.other

// Old saved recommendations have no kind; the first rule that matches wins (order matters)
const TEXT_RULES: Array<[RegExp, FixKind]> = [
    [/robots\.txt|crawler|gptbot|claudebot|google-extended|perplexitybot|unblock/i, 'crawler-access'],
    [/llms\.txt/i, 'llms-txt'],
    [/faq\s*page\s*schema|faqpage|faq.*schema|schema.*faq/i, 'faq-schema'],
    [/rating|aggregaterating|star/i, 'rating-schema'],
    [/\bvs\.?\b|versus|comparison/i, 'comparison-page'],
    [/\bfaq\b/i, 'faq-page'],
    [/review/i, 'reviews'],
    [/amazon|flipkart|nykaa|myntra|meesho|marketplace/i, 'marketplace'],
    [/reddit|subreddit|forum|quora/i, 'forums'],
    [/blog|outreach|press|\bpr\b|featured|influencer|listicle/i, 'outreach'],
    [/alt text/i, 'alt-text'],
    [/javascript|client-side|render/i, 'js-content'],
    [/collection/i, 'collection-schema'],
    [/schema|json-ld|structured data/i, 'product-schema'],
    [/description/i, 'description'],
    [/meta|title tag|page title/i, 'title-meta'],
    [/photo|image/i, 'images'],
    [/gtin|barcode|vendor|brand name/i, 'product-ids'],
    [/price|stock|inventory/i, 'price-stock']
]

const defaultMailer: Mailer = (m) => emailService.sendEmail(m.to, m.subject, m.text, { html: m.html, cc: m.cc, replyTo: m.replyTo })

const consumeSend = async (brandId: string) => {
    const today = new Date().toLocaleDateString('en-CA', { timeZone: 'Asia/Kolkata' })
    const same = await brandModel.updateOne({ _id: brandId, devSendDay: today, devSendCount: { $lt: DEV_SENDS_PER_DAY } }, { $inc: { devSendCount: 1 } })
    if (same.modifiedCount === 1) return true
    const fresh = await brandModel.updateOne({ _id: brandId, devSendDay: { $ne: today } }, { $set: { devSendDay: today, devSendCount: 1 } })
    return fresh.modifiedCount === 1
}

export const sendToDeveloper = async (
    brand: { _id: unknown; name: string; developerEmail?: string | null; products?: Array<{ shopifyId?: string | null }> },
    founder: { name: string; email: string; _id?: unknown },
    task: DeveloperTaskRef,
    email?: string,
    mailer: Mailer = defaultMailer
) => {
    const brandId = String(brand._id)
    let to = (brand.developerEmail || '').trim().toLowerCase()
    if (email !== undefined) {
        const e = email.trim().toLowerCase()
        if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(e)) throw httpErr(422, "Enter your developer's email, like dev@agency.in")
        if (isDisposableEmail(e)) throw httpErr(422, 'Use a real email address for your developer.')
        to = e
        await brandModel.updateOne({ _id: brandId }, { $set: { developerEmail: e } })
    }
    if (!to) throw httpErr(422, "Add your developer's email first.")
    const resolved = await resolveTask(brandId, task)
    if (!(await consumeSend(brandId))) throw httpErr(429, `You can send ${DEV_SENDS_PER_DAY} tasks a day. Try again tomorrow, or use Copy text.`)
    const { isShopify } = await guideContext(brand, [])
    const mail = buildDeveloperEmail(brand.name, founder.name || 'the store owner', resolved, isShopify)
    try {
        await mailer({ to: [to], cc: founder.email ? [founder.email] : undefined, replyTo: founder.email || undefined, ...mail })
    } catch {
        await brandModel.updateOne({ _id: brandId, devSendCount: { $gt: 0 } }, { $inc: { devSendCount: -1 } })
        throw httpErr(502, "Couldn't send. Use Copy text instead.")
    }
    const sentAt = new Date()
    await developerSendModel.create({ brandId, userId: founder._id, to, taskKey: taskKey(task), kind: resolved.kind, sentAt })
    return { sentTo: to, sentAt }
}

// The latest send per task of a brand, for "Sent to x · 2 days ago"
export const lastSends = async (brandId: string) => {
    const rows = await developerSendModel.aggregate([
        { $match: { brandId: new mongoose.Types.ObjectId(brandId) } },
        { $sort: { sentAt: -1 } },
        { $group: { _id: '$taskKey', to: { $first: '$to' }, at: { $first: '$sentAt' } } }
    ])
    return Object.fromEntries(rows.map((r) => [r._id as string, { to: r.to as string, at: r.at as Date }]))
}

            const { error, value } = validateJoiSchema<{ task: DeveloperTaskRef; developerEmail?: string }>(validationSendToDeveloperBody, req.body)

            const result = await sendToDeveloper(brand, authenticatedUser, value.task, value.developerEmail)
            httpResponse(req, res, 200, responceseMessage.SUCCESS, result)

            httpError(next, err, req, status ?? 500)
        }

    'Steps:',

- [ ] **Step 2: Write the component** `frontend/src/components/FixGuide.tsx`

```tsx
import { useState } from 'react';
import api from '../utils/axios';
import { timeAgo } from '../utils/timeAgo';
import { copyTextFor, taskKey, type DeveloperTask, type GuideContext } from '../utils/fixGuide';

interface Props {
  brandId: string;
  task: DeveloperTask;
  kind?: string | null;
  ctx: GuideContext;
  what: string; // the task text shown in Copy text
  code?: string;
  compact?: boolean;
  onEmailSaved?: (email: string) => void;
}

export default function FixGuide({ brandId, task, kind, ctx, what, code, compact, onEmailSaved }: Props) {
  const guide = ctx.guides[kind || ''] ?? ctx.guides.other;
  const [open, setOpen] = useState(false);
  const [asking, setAsking] = useState(false);
  const [email, setEmail] = useState('');
  const [busy, setBusy] = useState(false);
  const [msg, setMsg] = useState<{ ok: boolean; text: string } | null>(null);
  const [copied, setCopied] = useState(false);
  const last = ctx.lastSent?.[taskKey(task)];
  if (!guide) return null;

  const send = async (withEmail?: string) => {
    if (!withEmail && !ctx.developerEmail) { setAsking(true); return; }
    setBusy(true); setMsg(null);
    try {
      const res = await api.post(`/brands/${brandId}/send-to-developer`, { task, ...(withEmail ? { developerEmail: withEmail } : {}) });
      const to = res.data?.data?.sentTo as string;
      setMsg({ ok: true, text: `Sent to ${to}` });
      setAsking(false);
      if (withEmail) onEmailSaved?.(to);
    } catch (err: any) {
      setMsg({ ok: false, text: err.response?.data?.message || "Couldn't send. Use Copy text instead." });
    } finally {
      setBusy(false);
    }
  };

  const copy = async () => {
    try {
      await navigator.clipboard.writeText(copyTextFor(what, guide, ctx.isShopify, code));
      setCopied(true);
      setTimeout(() => setCopied(false), 2000);
    } catch {
      setMsg({ ok: false, text: 'Copy is blocked in this browser. Select the steps and copy them.' });
      setOpen(true);
    }
  };

  const steps = ctx.isShopify ? guide.steps.shopify : guide.steps.other;
  return (
    <div className={`fix-guide${compact ? ' compact' : ''}`}>
      <div className="fix-guide-row">
        <span className={`fix-guide-who ${guide.who}`}>{guide.who === 'you' ? 'You can do this' : 'Needs a developer'}</span>
        <button type="button" className="btn btn-ghost" onClick={() => setOpen(!open)} aria-expanded={open}>
          {open ? 'Hide steps' : 'How to do it'}
        </button>
        <button type="button" className="btn" onClick={() => send()} disabled={busy}>
          {busy ? 'Sending…' : 'Send to developer'}
        </button>
        <button type="button" className="btn btn-ghost" onClick={copy}>{copied ? 'Copied ✓' : 'Copy text'}</button>
      </div>
      {open && (
        <ol className="fix-guide-steps">
          {steps.map((s) => <li key={s}>{s}</li>)}
        </ol>
      )}
      {asking && (
        <div className="fix-guide-row">
          <input type="email" placeholder="Your developer's email" value={email} onChange={(e) => setEmail(e.target.value)} aria-label="Your developer's email" />
          <button type="button" className="btn btn-primary" disabled={busy || !email.trim()} onClick={() => send(email.trim())}>Save and send</button>
          <button type="button" className="btn btn-ghost" onClick={() => setAsking(false)}>Cancel</button>
        </div>
      )}
      {msg ? (
        <div className="fix-guide-msg" style={{ color: msg.ok ? 'var(--good)' : '#ef4444' }}>{msg.text}</div>
      ) : last ? (
        <div className="fix-guide-msg">Sent to {last.to} · {timeAgo(last.at)}</div>
      ) : null}
    </div>
  );
}
```
